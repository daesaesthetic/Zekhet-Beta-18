Build the MVP of a Discord.js bot named ⛤ Zekhet ⛤.

Zekhet is a mysterious personal attendant and keeper of records. His personality should be sophisticated, calm, slightly intimidating, and mystical. Use a dark purple/magenta fantasy aesthetic inspired by the bot's provided artwork.

Bot description:
"Your personal attendant & keeper of records."

TECHNICAL REQUIREMENTS:
- Node.js
- Discord.js
- SQLite
- Slash commands only
- Persistent data
- Environment variables for Discord credentials
- No AI
- No external APIs
- No web dashboard
- Do not use Message Content Intent
- Keep the project lightweight and simple
- Design personal functionality to support Discord USER_INSTALL where possible

MANDATORY COMMANDS:
- /help
- /credits

PROFILE SYSTEM — "THE RECORD":

Commands:
- /profile
- /profile user:@user
- /profile edit
- /profile bio
- /profile color
- /profile theme

A profile should display:
- Discord username
- Discord avatar
- Custom bio
- Equipped title placeholder
- Profile creation date
- Unique profile number

Allow these themes:
- Nightshade
- Celestial
- Eclipse
- Ancient
- Royal
- Void

Use polished Discord embeds. Do not create image-rendered profile cards for this MVP.

DATABASE:
Use SQLite.

Create only the tables needed for the current MVP:
- users
- profiles

Use Discord user ID as the primary identifier.

IMPORTANT:
Do not build titles, lore, curses, contracts, achievements, economy, leveling, server statistics, or unrelated systems yet.

However, structure the code cleanly so those systems can be added later.

USER INSTALLATION:
