You are continuing development of the existing ⛤ Zekhet ⛤ Discord bot.

CURRENT VERSION:
Zekhet-Beta-16

Beta-16 successfully implemented the core /venture gameplay system.

The next major update is:

⛤ ZEKHET-BETA-17 ⛤
THE INVENTORY & RELIC SYSTEM

==================================================
CORE OBJECTIVE
==================================================

Beta-16 established:

/venture
↓
Encounter
↓
XP / Deben / Outcome

Beta-17 should establish the next part of the gameplay loop:

/venture
↓
Encounter
↓
ITEM DISCOVERED
↓
/inventory
↓
Potential future /use system

The purpose of Beta-17 is to make items a meaningful part of Zekhet's gameplay.

IMPORTANT:

Do not rebuild the existing Venture system.

Do not replace the existing Inventory system if one already exists.

Do not create a second currency system.

Do not create a second XP system.

Reuse existing infrastructure wherever possible.

==================================================
1. ITEM DISCOVERY
==================================================

Connect the existing /venture system to the existing inventory system.

Some Venture encounters should be capable of awarding items.

Not every Venture should give an item.

Items should feel like discoveries rather than guaranteed rewards.

Example:

⛤ VENTURE COMPLETE ⛤

You uncover a small stone container beneath the ruins.

Inside:

🏺 ANCIENT SCARAB

Rarity: Uncommon

The artifact has been added to your inventory.

𓏏 +24 Deben
⭐ +16 XP
