Add two new features to the existing ⛤ Zekhet ⛤ Discord bot:

1. A customizable text command prefix.
2. A guided tutorial/progression system similar in concept to Mudae's /tuto.

IMPORTANT:
Zekhet is already functioning correctly.

Do NOT rebuild or replace existing systems:
- Profiles
- Titles
- Lore
- Curses
- Contracts
- Achievements
- Developer Console

Keep the existing slash commands working exactly as they do now.

==================================================
1. COMMAND PREFIX
==================================================

Add support for text-based commands using a customizable prefix.

Default prefix:

z!

Examples:

z!profile
z!titles
z!lore
z!achievements

The prefix should be configurable per server.

Add slash commands:

/prefix
/prefix set <prefix>
/prefix reset

/prefix should display the current server prefix.

Only users with appropriate server management permissions should be able to change the server prefix.

Default to:

z!

if a server has never configured one.

Keep the prefix short and practical.

Allow reasonable prefixes such as:

z!
zk!
zh!
>>

Do not allow extremely long prefixes.

Prevent prefixes containing whitespace or otherwise confusing characters.

==================================================
PREFIX COMPATIBILITY
==================================================

The bot's existing slash commands remain the primary interface.

Prefix commands should act as convenient aliases for supported commands rather than replacing slash commands.

Initially support aliases for the most useful commands:

z!profile
z!titles
z!lore
z!curse
z!contracts
z!achievements
z!help
z!credits
z!tuto

If an equivalent slash command requires arguments, allow the prefix version to accept those arguments where practical.

Example:

z!profile @user

z!title equip "The Forgotten"

Do not attempt to recreate every slash command as a prefix command if doing so would require unnecessary complexity.

Use the same underlying command handlers where possible so slash and prefix commands behave consistently.

IMPORTANT:
Prefix commands require the appropriate Discord Message Content Intent.

Do not break USER_INSTALL functionality for the existing slash-command systems.

==================================================
2. THE TUTORIAL — /tuto
==================================================

Create a guided tutorial/progression system called:

📜 THE TUTORIAL

Primary command:

/tuto

Prefix alias:

z!tuto

The tutorial should guide new users through Zekhet's major systems.

The system should contain multiple pages/chapters.

Users begin with the first page unlocked.

Completing all objectives on the current page unlocks the next page.

Previously completed pages should remain completed.

Tutorial progress must persist in SQLite.

Tutorial progress should be tracked per user.

When server-specific information is involved, associate that progress with the appropriate server/user context.

==================================================
